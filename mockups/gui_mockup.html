MicroCNC 0.3.0 — GUI proposal (mockup only, no code changed)

Dark, low-glare theme (good in a workshop next to a machine). One blue accent for normal actions, green only for "running / on", amber for pause, red only for Stop and E-STOP. Left column is fixed at 300 px; everything else goes to the view.
